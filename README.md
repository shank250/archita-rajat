# Royal Vows — Archita Srivastava & Rajat Ranjan's Wedding Invitation

A digital wedding invitation web application celebrating the union of **Archita Srivastava & Rajat Ranjan**, cordially extended by **Pramendra Kumar Srivastava & Prem Lata Srivastava, and The Kayastha Family**.

---

## 🌟 Key Features

1. **Auspicious Hero & Envelope Unveiling:**
   - Serene, crisp Lord Ganesha motif with sacred shloka (`॥ श्री गणेशाय नमः ॥`).
   - Realistic luxury post-mail envelope with postal stamp and wax seal.
   - Dynamic URL personalization (`?guest=Family+Name`).

2. **Formal Invitation Card:**
   - Auspicious invitation copy from the bride's parents (**Pramendra Kumar Srivastava & Prem Lata Srivastava**) along with **The Kayastha Family**.
   - Couple presentation with parental lineage:
     - **Archita Srivastava** (D/O Pramendra Kumar Srivastava & Prem Lata Srivastava)
     - **Rajat Ranjan** (S/O Ritu Ranjan Sinha & Madhu Sinha)

3. **Visual Storyboard Carousel:**
   - 100% visible childhood & couple portrait memories with ambient frosted glass framing.
   - Concise, heartfelt captions celebrating their journey.

4. **Unified Big Reveal Panel:**
   - Interactive scratch canvas overlay with deep wine matte finish and gold accents.
   - Comprehensive multi-event schedule revealed together:
     - **Engagement & Ring Ceremony:** 23 October 2026 @ Elegance Hotel, Gwalior
     - **Mehndi & Haldi Rasam:** 28 November 2026 @ Shital Niwas (Our Home), Gwalior
     - **Ladies Sangeet & Musical Night:** 29 November 2026 @ Shital Niwas (Our Home), Gwalior
     - **The Grand Wedding (Vivah Sanskar):** 30 November 2026 @ Krishna Lawn, Gwalior
   - Direct Google Maps directions and Google Calendar integration.
   - Refined, subtle gold sparkle effect.

5. **Dynamic Itinerary & Timeline:**
   - Interactive milestone schedule, event highlights, and attire guides for each occasion.

6. **Guest Essentials & Action Hub:**
   - One-tap calendar sync, WhatsApp celebration group, and multi-venue navigation modal.

7. **Heartfelt RSVP & Blessings Wall:**
   - Streamlined blessing submission without unnecessary RSVP checkboxes.
   - Interactive blessing feed with persistent local storage.

## 🛠️ Tech Stack

- **Framework:** React 18 + Vite 5 + TypeScript
- **Styling:** Tailwind CSS (Luxury wine `#881337`, warm cream `#FDFBF7`, gold accents)
- **Animation & FX:** Framer Motion + Canvas-Confetti
- **Icons:** Lucide React
- **Hosting Ready:** Vercel, Netlify, Cloudflare Pages

## 🌐 Deploying to Vercel

1. Push this repository to GitHub/GitLab/Bitbucket.
2. In [Vercel Dashboard](https://vercel.com/new), click **Add New Project** and select this repository.
3. Vercel automatically detects the Vite framework settings:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. Click **Deploy**. The `vercel.json` file ensures complete SPA routing and clean URL resolution.
